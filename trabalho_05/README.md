# Trabalho 05, Lista de Tarefas com Login e Salvamento via API

Aplicativo Flutter que expande a lista de tarefas do Trabalho 03 com telas de login e cadastro e salva a lista na API REST do professor, para que as tarefas voltem no próximo login. Feito para rodar no DartPad (só o `main.dart`). Quando a sessão expira, o app volta para a tela de login.

Rodar de dentro desta pasta com `flutter run -d chrome --dart-define-from-file=dados.json` (precisa do `dados.json` com a chave `API`).

# Assignment 05, To-Do List with Login and API Storage

Flutter app that extends the Assignment 03 to-do list with login and sign-up screens and saves the list to the professor's REST API, so tasks come back on the next login. Built to run on DartPad (just `main.dart`). When the session expires, the app returns to the login screen.

Run from inside this folder with `flutter run -d chrome --dart-define-from-file=dados.json` (requires `dados.json` with the `API` key).
