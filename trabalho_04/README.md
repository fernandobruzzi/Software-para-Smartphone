# Trabalho 04, Cadastro, Login e Lista de Tarefas via API

Programa Dart de console que usa a API REST do professor para cadastrar o usuário, fazer login, criar ou esvaziar sua lista de tarefas e imprimir o token JWT.

Rodar de dentro desta pasta com `dart run bin/main.dart` (precisa do `dados.json`).

# Assignment 04, Sign-up, Login and To-Do List via API

Dart console program that uses the professor's REST API to register the user, log in, create or empty their to-do list and print the JWT token.

Run from inside this folder with `dart run bin/main.dart` (requires `dados.json`).
